The tray: three compartments and a leaf.

Three moulded cells hold the base; the fourth has grown into a leaf. The cells are rounder than the first edition and the wordmark is set in Schibsted Grotesk, lowercase, so the mark reads as one object, not a grid. Use the horizontal lockup wherever it fits.

Built on a 120 unit grid.

Always place the master artwork; never redraw it. Below the minimum sizes the leaf closes up, so use the symbol alone instead of shrinking the lockup.

Cells 52 units, gap 8, corner radius 15. The leaf is an arc of radius 46 from the inner corner to the outer one.
