growtech brand kit, version 2.0 (November 2026)

Start with growtech-brand-guidelines.pdf. It explains how to use everything below.

logo/svg     Logos for websites and apps. Text is outlined, so no fonts are needed.
logo/pdf     Vector logos for printers and designers.
logo/png     Transparent PNGs for Word, PowerPoint and social media.
icons        App icon, icon 512, Apple touch icon, favicons and favicon.ico.
social       Facebook cover, LinkedIn banner, profile picture, two post templates.
stationery   Business card, A4 letterhead, DL envelope, email signature (HTML + image).
colours      Brand colours as CSS, JSON and a text sheet (HEX, RGB, approximate CMYK).
fonts        Space Grotesk, Inter and Hind Siliguri, with their SIL Open Font Licences.
qr           QR code that opens https://growtech.live
source       The guidelines as HTML with its images, to edit and export again.

Which logo file to use: SVG on screens, PDF for print, PNG only when a program cannot open the others.
